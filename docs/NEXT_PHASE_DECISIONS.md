## Ariel's decisions (override plan defaults)
1. **Build everything in the plan's MUST + SHOULD set**, including hygiene fixes (A1–A9), LLM seam (B), memory (C), companion (D), cadence/data (E1, E3), imagery (F1–F3).
2. **Imagery/detected tier is NOT limited to Tel Aviv + Jerusalem.** It covers all of Israel, made safe by **deny-by-default exclusion zones + per-candidate hazard filter + mandatory warnings** (see "Safety model"). It still ships **behind a flag, default OFF in production** (`NEXT_PUBLIC_DETECTED_TIER=1` to enable; Ariel's no-deploy-before-gate rule stands). No deploy/commit/push by builders.
3. **LLM model choice** — see "AI engine decision". Provider is env-selectable; no self-hosted GPU.
4. Dropped from scope (stay DEFER): offline SW, Google provider, shade routing, social, STT, kids mode, PostGIS preload E2 (write the migration + provider seam stub only if cheap; otherwise leave).

## AI engine decision (reasoned)
- Needs: understand free text (HE/EN), extract structured data, short grounded narration, remember prefs. Low volume (~$0.001–0.01/walk). Latency not critical (narration prefetched, in-walk logic deterministic).
- **Self-hosting an open-source model (Llama/Qwen/DictaLM) needs a 24/7 or serverless GPU (~$0.5–1.5/h or cold-start pain) — far costlier and more work than API calls at this volume, and Hebrew quality of small open models is weaker.** So: NO own cloud/GPU now.
- **Open-weight models via hosted inference (Groq/Together/OpenRouter-style OpenAI-compatible endpoint) are supported as an eval candidate** via an `openai-compatible` provider with `LLM_BASE_URL`. This gives "open source" without running servers. Revisit self-hosting only if monthly LLM spend > ~$100 or data-residency demands it.
- **Default (until eval says otherwise): Gemini 3.1 Flash-Lite pinned id, with Cloud Billing enabled (Ariel action A3: stops training on prompts)**; eval runner compares Haiku 5.5, gpt-6-luna/gpt-5-nano, Gemini 3.1 Flash-Lite, and one open-weight hosted model. Winner recorded in CLAUDE.md after Ariel runs the eval with real keys. Builders cannot run the eval live (no keys in agent env) — they build the runner + 70 cases (≥30 Hebrew) + a mock-provider dry run.
- Privacy: never send raw GPS or name; standing facts only if learning consent on; untrusted text in a data block.

## Safety model (applies to detected tier AND to anything suggested off-path)
1. **Deny-by-default zones** (`src/lib/places/safety-zones.ts`, data-driven, unit-tested): coarse conservative polygons/buffers that suppress detected-tier suggestions entirely: Gaza Strip + ~7 km envelope buffer line, Lebanon/Syria/Golan-border strip (~3 km), Jordan Valley/Arava/Egypt border strips (~1.5 km), Judea & Samaria (West Bank, all areas), East Jerusalem Old City surroundings is NOT excluded but flagged "mixed area" warning. Use simplified bounding polygons; mark file header: "coarse, conservative, must be reviewed by Ariel/security-aware human; false positives are OK, false negatives are not". Do not fabricate high-precision coordinates; use rough rectangles/polygons and a TODO list of what to refine. Outside Israel: detected tier off.
2. **Per-candidate hazard filter**: OSM landuse=military / military=*, firing zones, landuse=farmland/orchard/vineyard/greenhouse, private, fenced (barrier=fence/wall near), protected_area/nature_reserve (warn+hours), wadi/stream (flash-flood warn), cliffs, fire-season (Jun–Oct) warn, mined/danger tags → suppress or warn per plan §1.
3. **Reachability rule**: only suggest a detected area if a mapped walkable path/road enters/touches it within 150 m; never suggest "walk across" an unmapped area.
4. Mandatory on every detected card: "Detected from satellite data, not a registered place", at least one warning, "check signs/local rules", no "safe"/"verified" wording, confidence ≤ 0.8, HE+EN.
5. **Never the sole basis for navigation**; ORS/OSM paths only. Day-time bias: suppress detected suggestions when sun below horizon.
6. Emergency: show 100/101/102 hint? (UI footer in detected card only; keep small.)
